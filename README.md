# HR-Project
 Job Vacancies Module

This module allows HR personnel to manage job postings within the system. Features include creating new vacancies, updating vacancy information, viewing available positions, and removing inactive job postings. The module is connected to the database to ensure vacancy records are stored and updated properly.

## Application Module

This module enables applicants to apply for available job vacancies. Applicant information is validated and stored in the database. The module helps organize application records and supports the recruitment process by maintaining applicant data efficiently.
