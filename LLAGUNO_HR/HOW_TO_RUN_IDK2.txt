HOW TO RUN IDK2 (AdminApp)

Prerequisites:
- Windows desktop (WinForms UI requires interactive desktop session)
- .NET SDK 8.0 or later installed (`dotnet --info`)

Run the Admin UI (development):

From the `IDK2` folder:

```powershell
cd IDK2
dotnet restore
dotnet run --project AdminApp.csproj
```

Run the automated smoke test (verifies basic functionality and writes a report):

```powershell
dotnet run --project AdminApp.csproj -- smoketest
```

Run the built output directly (after building):

```powershell
dotnet bin\Debug\net8.0-windows\AdminApp.dll
```

Useful paths:
- App database (created next to the executable at runtime): `admin.db` (e.g., bin\Debug\net8.0-windows\admin.db)
- Smoke report: bin\Debug\net8.0-windows\smoke_report.txt

Stopping the app:
- From terminal: press Ctrl+C
- From UI: close the window

Troubleshooting:
- If the UI doesn't display, make sure you're on an interactive Windows session (not headless/remote without desktop).
- If build fails, run:

dotnet build "c:\Users\Ioan\OneDrive\Documents\IDK2\AdminApp.csproj"
